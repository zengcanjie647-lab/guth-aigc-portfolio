# guth · Video creation · AIGC

Personal AIGC portfolio featuring IP character design, production workflows,
e-commerce visuals, TVC concepts, creative video work, and AI short films.

## Local preview

Open `index.html` directly, or serve the folder with any static file server.

## Media

Portfolio videos are delivered as H.264/AAC at up to 1280 × 720 and 30 fps.
Large PNG artwork has been converted to WebP for faster mobile loading.

## GitHub Pages

The site is a static single-page website and can be published directly from the
repository root.
